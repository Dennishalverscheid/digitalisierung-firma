# Higgsfield Carousel Slide Prompt — Template

Instagram carousel slides have a different prompt shape than lifestyle posts. They lean type-driven, vertical, brand-coherent. Optimize for legibility on a 6" phone screen first.

```
4:5 VERTICAL INSTAGRAM CAROUSEL SLIDE, [SLIDE PURPOSE — hook / explainer / CTA / etc.],
visual concept: [one sentence describing the dominant visual idea],
typography: [serif / grotesque / mono] headline at [size descriptor], [secondary type style for supporting text if any],
layout: [centered / left-rail / asymmetric / type-only],
color palette: [3 anchor colors max — name them like 'soft cream #F5EFE6', 'deep navy', 'signal orange'],
texture: [matte flat / subtle paper grain / risograph dots / clean digital],
imagery (if any): [describe — generated illustration in X style / abstract shape / no imagery — type only],
mood: [2 adjectives],
brand cues: [where the brand mark goes, or 'no logo this slide'],
EXCLUDE: [stock photo people, generic gradient backgrounds, emoji, drop shadows on type, hashtag overlays, watermark text]
```

## Field guidance

- **Visual concept:** the ONE thing the slide communicates visually. "A typographic stat where the number is 80% of the slide height" beats "data visualization."
- **Typography:** name the family or feel. Don't say "modern font" — that produces nothing.
- **Color palette:** keep it to 3. The same 3 colors should appear across all 7 slides for the carousel.
- **Imagery:** be explicit about whether the slide has imagery at all. Most strong carousels are type-only on slides 2–6.
- **Brand cues:** name where the @ handle or logo goes (e.g. "small @ handle in bottom-right padding") or say "no brand mark — clean."

## Example — slide 4 ("How to use it"), AI for marketing operators niche

```
4:5 vertical Instagram carousel slide, slide purpose: explainer for "how to use this model in a real workflow",
visual concept: numbered 3-step workflow with each step in a separate horizontal band, monochrome with one signal color drawing the eye to the verbs,
typography: clean grotesque sans-serif (think Söhne or Inter Display), headline at 96pt, body at 32pt,
layout: left-aligned, generous left padding, three horizontal bands with thin dividers,
color palette: bone white #FBF7F0, deep ink #121212, signal orange #FF6A2B,
texture: clean digital with very subtle paper grain at 4% opacity,
imagery: no imagery — type-only,
mood: matter-of-fact, useful,
brand cues: small @ handle in bottom-right at 12pt, no logo,
EXCLUDE: stock photo people, gradient backgrounds, emoji, drop shadows on type, hashtag overlays, watermark text, decorative icons.
```

Fill every field. Carousel coherence dies the moment one slide goes off-spec.
