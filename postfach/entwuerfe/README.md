# Lokale Entwürfe

Nur genutzt, wenn kein Postfach verbunden ist. Der E-Mail-Manager legt hier je Entwurf eine Datei
`JJJJ-MM-TT_empfaenger_betreff.md` an (An, Cc, Betreff, Text). Du kopierst den Text ins Mailprogramm und sendest selbst.

Alle Dateien außer dieser README sind per `.gitignore` vom Repository ausgeschlossen (personenbezogene Daten).
