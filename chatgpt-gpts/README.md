[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT-Lizenz) plus der selbst entwickelte **E-Mail-Manager**.

## So legst du einen Custom GPT an (ChatGPT Plus/Team/Enterprise)
1. ChatGPT öffnen → **GPTs** → **Erstellen** → Reiter **Konfigurieren**.
2. Aus der gewünschten Datei übernehmen:
   - **Name** → Feld „Name“
   - **Beschreibung** → Feld „Beschreibung“
   - Alles unter **„Anweisungen“** → Feld „Anweisungen“ (jede Datei bleibt unter dem Limit von 8.000 Zeichen)
   - **Gesprächsstarter** → Felder „Gesprächsaufhänger“
3. Funktionen: **Websuche** an (für SEO, Marktforschung, Trends), **Code Interpreter** an (für Berichte, Finanzen, Dokumente), **Bildgenerierung** an (für Bild-Prompts, Social Media).
4. Optional unter **Wissen** Firmenunterlagen hochladen (Leistungsbeschreibung, Preisliste, Markenhandbuch, Textbausteine) – dann werden die Ergebnisse deutlich besser.
5. Speichern als **„Nur ich“** oder im Team-Arbeitsbereich für alle Kollegen.

**Ohne Plus-Abo:** In einem ChatGPT-**Projekt** den Anweisungs-Text in die Projekt-Anweisungen einfügen – oder einfach an den Anfang eines Chats kopieren.

## Wichtig
- Die GPTs ersetzen keine Rechts-, Steuer- oder Datenschutzberatung.
- Keine vertraulichen Kunden- oder Mitarbeiterdaten in ChatGPT eingeben, solange kein Business-/Enterprise-Vertrag mit Auftragsverarbeitungsvertrag (AVV) besteht.
